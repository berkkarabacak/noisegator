First-run setup

Set up your virtual microphone

Discord, Zoom, and Teams need a virtual microphone so they can hear the gated audio. NoiseGator cannot create a system microphone on its own — Windows requires a signed driver. The official free option is VB-CABLE from VB-Audio.

This does not stop the gate. You can Activate now and come back later.
