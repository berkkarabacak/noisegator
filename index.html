Desktop noise gate · 0.9

Cut the noise.
Hear yourself. Talk clean.

A microphone noise gate for VoIP. Gate the room, boost the send, and echo back a local monitor so you can hear yourself — then route the clean mic into Discord, Zoom, or Teams.

Download for Windows Source zip

Windows portable zip · Python 3.10+ · PortAudio ships in the sounddevice wheel

Built for the call

THR

Threshold knob

Circular gate threshold. Opens when the averaged level stays at or above the mark.

ms

Attack / Release

How long the level must stay above or below threshold before the gate moves.

%

Echo-back volume

Local hear-yourself monitor, separate from the dB send boost to the VoIP device.

Hz

Voice filter

40 Hz high-pass, 1.5 kHz low-pass, plus slow adaptive gain for speech clarity.

I/O

Device routing

Pick input, output, and an echo-back playback device — or Off for no extra stream.

Requirements

Windows 10/11. Python 3.10 or newer (the zip’s NoiseGator.bat launches pythonw app.py).

A virtual audio cable for VoIP — VB-Cable is the usual pick. NoiseGator does not create a virtual microphone.

On Windows, pip install sounddevice wheels usually bundle PortAudio. No extra DLL hunt.

VoIP routing

  1. Input → your real microphone
  2. Output → VB-Cable Input (virtual)
  3. Echo-back → headphones / speakers, or Off
  4. In Discord / Zoom / Teams, set the mic to the cable’s playback device
