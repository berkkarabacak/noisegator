Controls

What the gate actually does

Threshold in dB

Knob from −60 to 0 dB. A dashed line on the waveform marks the same level. Opens when the attack-window average stays at or above it.

Hysteresis

Closes only after the level drops below threshold minus hysteresis, so the gate does not chatter around the line.

Attack / Release

How long the level must stay above or below threshold before the gate moves.

Echo-back

Local hear-yourself monitor — its own volume and playback device, separate from the send to VoIP.

Voice filter

40 Hz high-pass, 1.5 kHz low-pass, plus slow adaptive gain for speech.

Routing

Pick input, output, and an echo-back device — or Off. The app does not create a virtual mic.
